# 01 · 快速开始

从零把《神秘幸存者》跑起来，只需要三步。

---

## 1. 装 Godot 4.7

到 [Godot 官网](https://godotengine.org/download) 下载 **Godot 4.7 标准版**。

> ⚠️ 不要用 .NET 版：项目全部是 GDScript，没有任何 C# 代码。
> 版本也不要太低 —— 工程用的是 Godot 4.7 的 `.scn` / `.uid` 格式。

## 2. 打开工程

```text
用 Godot 打开仓库根目录下的 project.godot
```

第一次打开时 Godot 会扫描并导入全部资源（`sucai/` 里的图比较多，可能要等一会儿）。
导入完成后，编辑器会记住上次打开的场景。

## 3. 运行

| 快捷键 | 作用 |
| --- | --- |
| `F5` | 运行整个游戏（主场景 `scene/大场景/main_map.scn`） |
| `F6` | 只运行当前打开的场景 |
| `F8` | 停止运行 |

启动后玩家会出现在**主地图**上：走到左上角的传送门里，就会进入战斗场景
`scene/大场景/game.scn`。这部分新设计见 [05-大厅与传送门](05-大厅与传送门.md)。

## 常用的调试方式

### 单独跑某个场景

想调敌人、能力、界面，直接打开对应的 `.tscn` 按 `F6`。
其中敌人场景在没有管理器的情况下也能跑（血量、移动组件都是自洽的）。

### 打开设置界面

局内的设置界面是 `scene/ui/settingscreen_ingame.tscn`（音量、摇杆位置、光照、全屏都在里面）。

> ⚠️ 它目前只能从「升级选卡界面按 Esc」打开：
> 玩家身上那颗暂停按钮在 `player.tscn` 里默认是隐藏的，
> 而 `scene/ui/通用/暂停.tscn` 还没有被任何场景引用。详见 [08-开发路线](08-开发路线与待办.md) 的「已知问题」。

### 成就存档

成就数据存在用户目录：

```text
Windows: %APPDATA%\Godot\app_userdata\神秘幸存者\achievements.save
```

删掉它就能清空成就进度（`resource/achievement/achievement_resource.gd` 里定义了存档格式）。

### 根目录的几个 Python 小工具

仓库根目录有几个脚本作者自己写的素材检查工具，用 Python 3 直接跑：

| 文件 | 作用 |
| --- | --- |
| `cross_ref.py` | 扫描所有 `res://` 引用，列出工程里**没有任何地方引用**的素材 |
| `cross_ref2.py` | 同上，更严格的版本 |
| `summary.py` | 汇总未被引用的素材，并按体积排序（找可以删的大文件） |
| `verify.py` | 检查一批指定素材是否被引用 |

> 这些脚本里的路径是硬编码的，换机器需要改开头的 `base` 变量。

## 导出

`export_presets.cfg` 里已经准备好三个预设：

| 平台 | 预设 | 备注 |
| --- | --- | --- |
| Windows | `Windows Desktop` | 主要发行平台，直接「导出项目 → 发布」 |
| macOS | `macOS` | 需要在导出设置里填签名 / 公证信息 |
| Android | `Android` | 需要配置 Android SDK 与 keystore；构建中间产物在 `android/build` |

菜单：**项目 → 导出…**，选好预设 → 「导出项目」。

> 导出前建议先运行一遍 `项目 → 工具 → 重新加载项目`，
> 确保所有资源的 UID 缓存是最新的。

## 常见问题

**Q：打开工程后大量资源显示"找不到"？**
A：多半是导入没跑完。关掉 Godot 再开一次，或执行「项目 → 重新加载项目」。

**Q：运行后黑屏 / 直接闪退？**
A：先按 `F5` 看控制台第一条红字；最常见是主场景被改成了不存在的路径，
见 `project.godot` 里 `run/main_scene`。

**Q：中文路径会不会出问题？**
A：工程里大量目录是中文（`scene/大场景`、`script/ui`），
Godot 本身没问题，但**部分第三方插件和命令行工具**可能不认中文路径，
遇到诡异问题可以先试试把工程挪到纯英文路径下。

**Q：改了 `.gd` 之后类名报 "Could not resolve class"？**
A：Godot 的全局类名缓存在 `.godot/` 里，新加的 `class_name` 偶尔要等编辑器扫一遍。
实在不行就重启编辑器（这个目录不进版本库，删掉也没事）。
