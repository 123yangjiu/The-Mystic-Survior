## 六、给下一个接手的人

- 先读 [03-架构总览](03-架构总览.md)，尤其 `GameEvent` 和"组件拼装"那两节；
- 改数值之前先看 `resource/` 里的 `.tres`，很多东西不用改代码；
- 场景之间的引用**小心循环依赖**，这次已经踩过一次（见 [05](05-大厅与传送门.md)「常见问题」）；
- 提交前用 `F5` 走一遍：大厅 → 传送门 → 打一局 → 死掉 → 返回大厅。
