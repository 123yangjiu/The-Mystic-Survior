# 12 · 模板与工具函数

> 写新内容之前先翻这一页：**能套模板就不新建，能调工具函数就不重写**。
>
> 这份文档是给"要往游戏里加东西"的人（包括 AI）看的：
> 先找到对应模板 → 复制 / 继承 → 只写这个模板留给你的那几个虚函数。

---

## 一、开工前的三条规则

1. **先出方案，再动手**
   - 新场景：先把完整节点树（节点名 / 类型 / 关键属性 / 挂什么脚本）写出来；
   - 新脚本：先说明 `extends` 谁、父类是哪条链、重写哪些方法、新增函数给谁调用；
   - 改现有内容：先说改哪个文件哪个函数、会影响谁。
2. **优先复用模板**：敌人、能力、刷怪事件、互动物件、状态效果、UI 都有现成模板，复制比新写快且不会和现有系统打架。
3. **优先复用工具函数**：尤其 [enemy_producer.gd](../script/manager/enemy_producer.gd)（刷怪）、[确认物体.gd](../script/场景互动件/确认物体.gd)（互动）、[portal.gd](../script/场景互动件/portal.gd)（传送门）这三处，写新东西基本都能套。

## 三、敌人模板

### 1. 节点树（`scene/enemy/enemy_template.tscn`）

```text
slime (CharacterBody2D)              script = enemy_xiaotrue.gd（class_name Enemy）
├── AnimatedSprite2D                 组 "enemy"，动画帧
├── health_component      → HealthComponent        血量、died 信号
├── wound_component       → WoundComponent         受击判定 + 白闪 + 飘字
├── AttackComponent       → AttackComponent        接触伤害（按 type 决定打谁）
├── velocity_component    → VelocityController     追击 / 转向
├── CollisionController   → CollisionComponent     实体碰撞（挡路）
├── drop_component        → DropComment            死亡掉落
└── EffectComponent       → EffectComponent        "看不见的敌人"等表现
```

### 2. 加一个新敌人（4 步）

1. 复制 `enemy_template.tscn` → 改名，换 `AnimatedSprite2D` 的贴图，按需要增删组件；
2. 在 `resource/enemy/` 新建一个 `EnemyUnlockEntry` 资源，填：`ID / scene / unlock_difficulty / disapear_difficulty / weight / max_health`；
3. 把这条资源拖进 [enemy_manager.tscn](../scene/manager/enemy_manager.tscn) 根节点的 `normal_enemy`（或 `special_enemy`）和 `all_enemy`；
4. 需要在代码里特判的行为，在 [enemy_xiaotrue.gd](../script/enemy/main_enemy/enemy_xiaotrue.gd) 里用 `_id` 判断（现有例子：骑士 / 巫婆 / 亡灵的死亡计数）。

### 3. 组件基类的约定

所有组件继承 [EnemyComponent](../script/class/enemy_component.gd)，**不用自己连父节点**：

```gdscript
class_name EnemyComponent
extends Node2D

func _ready() -> void:
	# 自动找到自己是哪个 Enemy 的组件，登记进 owner.all_component
	...
	initial()          # ← 子类只需要重写这个

func initial()->void:
	pass
```

- 想读主人的血 / 精灵：`owner.health_component`、`owner.animated_sprite_2d`；
- 想让敌人知道"自己被这块区域打到了"：给区域套 `AreaInComponent`，
  受害者用 `area.return_component()` 反查组件。

## 四、能力模板

### 1. 继承链

```text
Node2D
└── AbilityController            定时释放的通用骨架（冷却 / 伤害 / 数量 / 音量 / 升级响应）
    ├── FlyAbilityController     飞出去打人（剑、火球）
    │   └── AK47AbilityController 枪械（装弹 / 连发 / 后坐力 / 转头）
    └──（直接继承）圣光、光环、天堂之怒
```

飞行物：`FlyThing`（子弹、剑、火箭）；留在原地造成伤害：`AgainstThing`（光环、圣光）。

### 2. `AbilityController` 里已经写好的东西

| 成员 | 说明 |
| --- | --- |
| `@export ability:PackedScene` | 要生成的飞行物场景 |
| `@export timer:Timer` | 攻击间隔 |
| `@export audio:AudioStreamPlayer2D` | 攻击音效 |
| `number` / `number_range` | 每次攻击数量 |
| `init_damage` / `damage_range` | 伤害 |
| `init_scale` / `scale_range` | 飞行物大小 |
| `base_wait_time` / `wait_range` | 冷却 |
| `volume` / `volume_range` | 音量 |
| **`set_variable()`（虚）** | **在这里填你这套能力的基础数值** |
| `attack(target)` / `set_base()` / **`set_plus()`（虚）** | 生成与摆放飞行物，`set_plus` 放"个性化的朝向/位置修正" |
| `on_ability_upgrade_add(upgrade, current)` | 监听升级；用 `match upgrade.ID` 加自己的强化 |
| `set_speed(gap)` | 统一处理冷却 / 音量递减 |

### 3. 加一个新能力（4 步）

1. `scene/ability/<系列>/` 复制一个接近的控制器场景（内含 `Timer`、`AudioStreamPlayer2D`）；
2. `script/ability/controller/` 新建脚本，`extends AbilityController`（或 `FlyAbilityController`），
   重写 `set_variable()` 填数值、`set_plus()` 做特殊摆放、按需重写 `on_ability_upgrade_add()`；
3. 飞行物直接复用 `scene/ability/<系列>/` 里现成的子弹 / 剑场景，或基于 `FlyThing` 新建；
4. 在 `resource/upgrades/<系列>/` 加升级卡，并把卡拖进 [game_event.tscn](../scene/大场景/game_event.tscn) 根节点的 `upgrade_pool`。

升级卡（`AbilityUpgrade`）关键字段：`ID / Sort / is_init（初始就有）/ is_unlock（解锁型）/
self_lock / lock_code（互斥）/ Description`。

## 五、刷怪工具箱（写新事件必看）

### 1. 现成函数（[enemy_producer.gd](../script/manager/enemy_producer.gd)）

| 函数 | 作用 |
| --- | --- |
| `single_appear(enemy, distance:=500.0)` | 在玩家附近刷 1 只 |
| `line_front(enemy, wave:=2, wait_time:=4.0, distance:=280.0)` | 借阵型从某个方向成排冲来 |
| `circle_surround(enemy, s_radius:=420.0, number:=70.0, wait_time:=0.0, is_slow:=true, direction:=1.0)` | 围成一圈（半径 ±2% 抖动，可减速 / 反向） |
| `circle_interval(enemy, wave:=3, s_radius:=280.0, number:=16, wait_time:=0.1)` | 一圈圈往里缩 |
| `limit_position(pos) -> Vector2` | 把坐标夹进地图边界（`left_limit = -2850` 等常量） |
| `find_enemy(EnemyUnlockEntry.ALL_ID) -> EnemyUnlockEntry` | 按 ID 取敌人配置 |
| `find_shape(EnemyManager.ALL_SHAPE) -> EnemyShape` | 按类型取阵型 |
| `normal_special()` / `real_special()` | 随机挑一个普通事件 / 威胁事件执行 |
| `attach_out_view_reaper(enemy)` | 给一只敌人挂"离开屏幕就回收"的组件（箭线阵型在用，其它事件也能复用） |

### 2. 已经有的特殊事件（照它们的写法复制）

| 函数 | 效果 |
| --- | --- |
| `mushroom_circle()` | 蘑菇雨（临时改刷怪半径与统计频率） |
| `collision_disappear()` | "看不见的敌人"（发 `GameEvent.collision_disappear`） |
| `boss_come()` | Boss 登场（按难度指数决定数量） |

### 3. 注册一个新事件

```gdscript
func _ready() -> void:
	all_special_event.append(line_front)
	all_threat_event.append(mushroom_circle)
	all_threat_event.append(my_new_event)     # ← 加在这里

func my_new_event() -> void:
	var enemy = find_enemy(EnemyUnlockEntry.ALL_ID.wolf)
	circle_surround(enemy, 420.0, 40)
	await get_tree().create_timer(3.0, false).timeout
	single_appear(find_enemy(EnemyUnlockEntry.ALL_ID.knight))
```

- `all_special_event` 里的事件**会被随机挑中并传入一个敌人配置**（函数要能收一个参数）；
- `all_threat_event` 里的事件**自己决定刷什么**（无参）；
- 想固定在某个难度触发，就写进 `on_more_difficulty(difficulty)` 的 `match` 分支。

### 4. 阵型

`EnemyShape`（[shape.gd](../script/enemy_event/shape.gd)）：一个 `Node2D`，导出 `all_enemy`（刷怪点父节点）和 `type`。
现有 4 个阵型场景，`enemy_manager.all_shape` 里注册了 3 个（`triangle_line` 还没注册）：

| 场景 | 形状 |
| --- | --- |
| `arrow_line.tscn` | 箭头形 |
| `gappy_line.tscn` | 缺口横排 |
| `titled_line.tscn` | 斜排 |
| `triangle_line.tscn` | 三角（未注册） |

## 六、可互动物件

### 1. 靠近 + 按确认键（[确认物体.tscn](../scene/场景互动件/确认物体.tscn)）

```text
确认物体 (Node2D)                  script = 确认物体.gd（class_name ConfirmStuff）
├── AnimatedSprite2D               外观
├── CollisionArea (Area2D)         mask = 玩家实体（32），"碰到了"
│   └── CollisionShape2D
├── CheckArea (Area2D)             比上面大一圈，"在附近"
│   └── CollisionShape2D
└── Interval (Timer, 0.5s)         防止连按
```

| 已写好的函数 | 说明 |
| --- | --- |
| `_ready()` | 自动连接两个 Area 和 Interval |
| `_on_check_body_entered(body)` | 玩家进入"附近"，置 `is_player_entered` |
| `_input(event)` | 检测 `confirm` 键 + 冷却 |
| **`input_event()`（虚）** | **你只需要重写这个** |
| `_on_interval_timer_timeout()` | 冷却结束 |

```gdscript
extends ConfirmStuff

func input_event() -> void:
	var screen = preload("res://scene/ui/图鉴/skill_tujian.tscn").instantiate()
	add_child(screen)
```

### 2. 走进门触发（[portal.tscn](../scene/场景互动件/portal.tscn)）

`Portal`（[portal.gd](../script/场景互动件/portal.gd)）负责外观：`open()` / `play_enter()` / `close()` /
`set_wake(true/false)` / `set_emitting(true/false)`。
玩家版子类 [player_portal.gd](../script/场景互动件/player_portal.gd) 只做"谁进来 → 等他被吸进去 → 切场景"。

## 八、状态效果模板

`StatusEffect`（[status_effect.gd](../script/status_effect/status_effect.gd)）已经处理好：

- `attach_effect(target, time)`：如果目标身上已有同种效果，只**刷新时间**，不会叠两个；
- 计时结束自动 `recover_effect()` 并销毁。

新效果只需要重写三个空函数：

| 函数 | 时机 |
| --- | --- |
| `single_effect()` | 刚挂上时执行一次 |
| `cycle_effect()` | 需要周期性生效的写这里 |
| `recover_effect()` | 结束时复原（务必把改过的东西改回去） |

现成例子：[effect_confusion.gd](../script/status_effect/effect_confusion.gd)（混乱：改 `InputMap` + 摇杆映射）。
