## 三、主题与字体

`project.godot` 里全局指定了：

```ini
[gui]
theme/custom="uid://dbgauou15hq13"
theme/custom_font="uid://ceoy0esmffpt8"
```

| 资源 | 文件 | 用途 |
| --- | --- | --- |
| 像素中文字体 | `resource/theme/fusion-pixel-12px-monospaced-zh_hans.ttf` | 全局默认字体（12px 等宽像素字体） |
| `green_theme` | `resource/theme/green_theme.tres` | 绿底按钮，主界面 / 大厅用 |

## 四、音频总线

`default_bus_layout.tres` 定义了三条总线：

```text
Master
├── Music   (BGM：主界面、战斗分段音乐)
└── Sound   (音效：攻击、受伤、音效包)
```

代码里设总线的方式是直接写名字：

```gdscript
_music.bus = &"Music"
audio.bus = "Sound"
```

设置界面里的三个音量滑条（`Master_bar` / `music_bar` / `sound_bar`）
直接改 `AudioServer` 对应总线的音量，并把数值记到 `GameEvent.master_db` 等变量里，
下次打开设置能还原。

## 五、导入设置

`project.godot` 的渲染设置对这个像素游戏很关键：

| 设置 | 值 | 作用 |
| --- | --- | --- |
| `textures/canvas_textures/default_texture_filter` | `0`（Nearest） | 像素图放大不糊 |
| `2d/snap/snap_2d_transforms_to_pixel` | `true` | 避免像素抖动/半像素 |
| `textures/vram_compression/import_etc2_astc` | `true` | 移动端纹理压缩 |
| `display/window/size/viewport_width/height` | `640 × 360` | 逻辑分辨率（像素风） |
| `display/window/stretch/mode` | `viewport` | 整数缩放，窗口 1920×1080 |

所以写新特效时**不要用半像素坐标**，也不要给它开线性过滤 —— 会和整体风格打架。
（`portal.tscn` 里只有那一张渐变光晕开了线性过滤，因为它是程序生成的渐变图，
不是像素画，模糊一点反而好看。）

## 六、找"没用到的素材"

仓库根目录的 `cross_ref.py` / `summary.py` 会扫描所有 `res://` 引用，
把**没有任何场景/脚本引用**的素材列出来，并按体积排序。

清理素材前先跑一遍，能避免删掉以后还要用的东西
（注意：脚本里硬编码了旧路径，换机器要改 `base` 变量）。
