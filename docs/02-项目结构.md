# 02 · 项目结构

想找某个功能在哪，先翻这一页。

> 约定：`scene/` 放场景，`script/` 放脚本，两边的**子目录名字基本一一对应**
> （例如 `scene/enemy_component/` ↔ `script/enemy_component/`）。
>
> 要**加新内容**（新敌人 / 新能力 / 新刷怪事件 / 新互动物件）时，先看
> [12-模板与工具函数](12-模板与工具函数.md) —— 那里有模板和现成函数，别从零手搓。

---

## 顶层目录

| 目录 / 文件 | 放什么 |
| --- | --- |
| `project.godot` | 工程配置：主场景、输入映射、物理层名、主题字体、自动加载 |
| `scene/` | 所有 `.tscn` / `.scn` 场景 |
| `script/` | 所有 `.gd` 脚本 |
| `resource/` | 数据资源（`.tres`）：能力升级表、敌人解锁表、主题、成就 |
| `sucai/` | 美术与音频素材，按来源分目录 |
| `docs/` | 就是你现在看的文档 |
| `addons/` | 第三方编辑器插件（`hasturoperationgd`，一个能在编辑器里执行 GDScript 的 MCP 工具） |
| `android/` | Android 导出产生的工程文件 |
| `editor/` | 编辑器扩展源码（目前只有 `docks/scene_tree_dock.cpp`） |
| `scene_template/` `script_templates/` | Godot 的「新建场景 / 新建脚本」模板 |
| `export_presets.cfg` | 导出预设（Windows / macOS / Android） |
| `*.py` | 作者自用的素材引用检查脚本，见 [01-快速开始](01-快速开始.md) |

## scene/ 场景

### 大场景（核心）

| 场景 | 说明 |
| --- | --- |
| `大场景/main_map.scn` | **游戏主场景（大厅）**。玩家一进游戏就在这里，通过地图上的物品互动使用各种功能 |
| `大场景/game.scn` | **战斗场景**。一张大地图 + 刷怪管理 + 计时 + 全屏 UI |
| `大场景/game_event.tscn` | **自动加载**：全局信号总线 `GameEvent`（详见 [03-架构总览](03-架构总览.md)） |
| `大场景/maintheme.tscn` | 旧的主界面。**已停用**，保留仅作参考 |

> `main_map.scn` 和 `game.scn` 是 **二进制场景**（`.scn`），
> 在编辑器里双击打开即可，和 `.tscn` 用起来没有区别。

### 场景互动件（大厅里的可互动物品）

| 场景 | 说明 |
| --- | --- |
| `场景互动件/portal.tscn` | **传送门**：走进来就进入战斗场景（见 [05-大厅与传送门](05-大厅与传送门.md)） |
| `场景互动件/确认物体.tscn` | 「靠近 + 按空格」互动物品的**模板**，脚本是 `ConfirmStuff` |
| `场景互动件/难度切换.tscn` | 靠近弹出四块面板、点击切换难度的物件（`DifficultySwitcher` + `DifficultySegment`） |
| `场景互动件/训练场门.tscn` | 主世界通往训练场的绿门（`Portal` 的实例，`theme_color` + `portal_name` 区分） |
| `大场景/训练场.tscn` | 训练场：草地 + 隐形墙（80×44 格）+ 玩家 + 3 个沙包 + 绿色返回门 |
| `测试用场景/组件展示.tscn` | 组件展示：一排只有外观的传送门（带目的地标签），按 F6 直接看 |
| `场景互动件/图鉴终端.tscn` | 靠近按空格打开图鉴的终端（`codex_terminal.gd`） |
| `ui/图鉴.tscn` | 全屏图鉴界面（`Codex`，数据来自 `CodexData`） |
| `场景互动件/confirm_change_nandu.tscn` | 难度确认物（占位，尚未完成） |
| `模板/特效/portal.tscn` | 一个"裸"传送门模板，只有一个空的 AnimatedSprite2D + Area2D |

### 玩家与战斗

| 目录 | 内容 |
| --- | --- |
| `player.tscn` | 玩家：移动、血量、受伤区、拾取范围、四种能力控制器、虚拟摇杆、暂停按钮 |
| `ability/` | 剑、火球、圣光、光环、天堂之怒、枪械（`AK47_ability/` 下含 AK / 霰弹 / 狙击 / RPG） |
| `enemy/` | 15 种敌人 + `enemy_template.tscn`（新敌人从这里复制） |
| `enemy_component/` | 敌人身上的各种组件，见下表 |
| `enemy_event/` | 特殊刷怪阵型（箭头阵、缺口阵、三角阵……）与表现层 |
| `瓶子/` | 经验瓶 / 血瓶 / 增益瓶 |
| `status_effect/` | 状态效果（目前有"混乱"：打乱方向键 + 摇杆） |

**敌人组件（`scene/enemy_component/`）**

| 目录 | 组件 | 作用 |
| --- | --- | --- |
| `main_component/` | `HealthComponent` | 血量、死亡信号 |
| | `WoundComponent` | 受伤判定（受伤区域 + 受击白闪 + 飘字） |
| | `AttackComponent` | 攻击判定（接触伤害、穿透伤害） |
| | `VelocityController` | 移动 / 转向 / 加速 |
| | `CollisionComponent` | 实体碰撞（挡在玩家面前） |
| | `DropComponent` | 死亡掉落瓶子 |
| | `EffectComponent` | 特殊表现（"看不见的敌人"时显示狼影） |
| `chid_component/` | `player_wound_component` | 玩家专用受伤（带无敌帧） |
| | `escape_component` / `velocity_near_component` | 逃跑 / 近身行为 |
| | `check_attack_component` / `check_ability_component` | 条件触发攻击 / 能力 |
| | `box_drop_component` | 打死掉箱子 |
| | `solid_velocity_component` / `solid_collision_controller` | 有实体碰撞的移动 |
| | `with_animation_attack_component` | 攻击时同步播放动画 |
| `inside_scene/inside_collision.gd` | `AreaInComponent` | 关键胶水：任何"伤害区"都套这一层，用来反查它属于哪个组件 |
| 其它 | `blink_component` `copy_component` `disappear_component` `disappear_out_view_component` `invisible_component` `rush_component` `summon_component` | 闪现、复制、消失、出屏消失、隐身、冲锋、召唤 |

### 管理器（`scene/manager/`）

| 场景 | 脚本 | 作用 |
| --- | --- | --- |
| `enemy_manager.tscn` | `EnemyManager` | 敌人解锁池、权重随机、刷怪间隔、难度联动 |
| （挂在 enemy_manager 下） | `enemy_producer.gd` | 具体刷怪位置与特殊事件（包围圈、Boss 登场……） |
| `upgrademanager.tscn` | `upgrademanager.gd` | 升级三选一、能力池、神秘池 |
| `experiencemanager.tscn` | `experiencemanager.gd` | 经验、等级、升级信号 |
| `gametimemanager.tscn` | `gametimemanager.gd` | 一局的倒计时（默认 600 秒）、胜利 |
| （game.scn 内） | `musicmanager.gd` | 分段音乐（越打越激烈） |

场景脚本**不放在** `scene/ui` 里，统一放在 `script/ui/<同名文件夹>/`。

## script/ 脚本

### 入口与全局

| 脚本 | 类名 | 说明 |
| --- | --- | --- |
| `script/gamevent.gd` | — | **自动加载**的全局单例 `GameEvent`：信号总线 + 全局状态 |
| `script/game.gd` | `Game` | 战斗场景启动逻辑（⚠️ 目前**没有挂到 game.scn 的根节点上**，是历史遗留） |
| `script/player.gd` | `Player` | 玩家移动、受伤、拾取、能力升级回调 |
| `script/拾取范围.gd` | — | 玩家吸经验的范围（"吸铁石"升级会放大它） |
| `script/大场景/main_map.gd` | — | **大厅**：清状态、放大厅音乐 |
| `script/大场景/screen_fade.gd` | `ScreenFade` | 跨场景淡入淡出 |

### 基类（`script/class/`）

| 脚本 | 类名 | 说明 |
| --- | --- | --- |
| `enemy_component.gd` | `EnemyComponent` | **所有敌人组件的基类**：自动认领 `owner` 并登记到 `Enemy.all_component` |
| `ability_controller_class.gd` | `AbilityController` | 所有"定时释放"能力的基类（冷却、伤害、数量、音量） |
| `flyability_controller.gd` | `FlyAbilityController` | 飞出去打人的能力（剑、火球） |
| `AK47_controller.gd` | `AK47AbilityController` | 枪械类能力 |
| `fly_thing.gd` | `FlyThing` | 飞行物本体（子弹、剑、火箭） |
| `against_thing.gd` | `AgainstThing` | 留在原地造成伤害的东西（光环、圣光柱） |
| `change_button.gd` | `ChangeButton` | 设置里的"开关型"按钮 |
| `turn_screen.gd` | `TurnScreen` | 全屏切换类界面 |

### 场景互动件（`script/场景互动件/`）

| 脚本 | 类名 | 说明 |
| --- | --- | --- |
| `portal.gd` | `Portal` | 传送门**外观动画**（呼吸 / 光环 / 粒子 / 收缩 / 爆发） |
| `player_portal.gd` | — | 传送门**逻辑**：玩家进入 → 开始一局 → 切场景 |
| `确认物体.gd` | `ConfirmStuff` | "靠近 + 按确认键"互动物品的模板 |
| `confirm_change_nandu.gd` | — | 难度确认物（未完成） |

### 其他

| 目录 | 内容 |
| --- | --- |
| `script/ability/` | 各能力的控制器与飞行物逻辑 |
| `script/enemy/` | `Enemy` 主类（`enemy_xiaotrue.gd`）、敌人筛选器、Boss |
| `script/enemy_component/` | 与场景目录同名的组件脚本 |
| `script/manager/` | 五个管理器 + 音乐管理器 |

| `script/component/` | 一些通用小部件（hitbox / hurtbox / disappear） |
| `script/测试场景/` | 作者自己的测试脚本，可以不管 |

## resource/ 数据资源

| 路径 | 内容 |
| --- | --- |
| `ability_upgrade.gd` | `AbilityUpgrade` 资源类：ID、分类、描述、是否解锁型、锁定码…… |
| `upgrades/**/*.tres` | 全部升级卡片（剑 / 火球 / 枪 / 光环 / 圣光 / 天堂之怒 / 通用） |
| `enemy/enemy.gd` | `EnemyUnlockEntry` 资源类：敌人 ID、解锁难度、权重、血量 |
| `enemy/*.tres` | 每种敌人一条数据 |
| `theme/*.tres` | 四套 UI 主题 + 像素中文字体 `fusion-pixel-12px` |
| `achievement/` | 成就管理（自动加载 `AchievementManager`）与存档逻辑 |
| `else/tile.tres` | 地图用的 TileSet |
