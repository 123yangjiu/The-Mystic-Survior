几点说明
· 主世界的难度切换物件有四块（简单 / 普通 / 困难 / 挑战），每块用 mode_index 自己记住对应难度；
· 现在选「挑战」= 三个挑战 tag 全部打开（GameEvent.select_mode(3)），以后做 tag 界面再改这一个函数；
· 成就判定在 victoryscreen.gd：普通通关 → normal_finished，困难通关 → hard_finished，挑战三 tag 全开通关 → all_challenge_finished，困难及以上一只特殊怪都不杀 → love_and_peace。
